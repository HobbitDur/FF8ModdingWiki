-   Opcode: **0x121**
-   Short name: **LSCROLL3**
-   Long name: Scroll a background layer

#### Argument

none

#### Stack

*Layer*, *Start X*, *Start Y*, *End X*, *End Y*, *Frames*

**LSCROLL3**

#### Description

Sets one background layer scrolling from a start to an end position over a number of frames: mode 4 of the layer scroll state.

PC handler: `SCRIPT_LSCROLL3`.

## Function addresses

| Function | Address | Description |
|---|---|---|
| `SCRIPT_LSCROLL3` | 0x521530 | Field script opcode handler (verified IDA function) |
