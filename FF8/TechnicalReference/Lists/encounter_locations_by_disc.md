Where and when every encounter of `scene.out` is met: field area or world-map region -> disc / story point ->
encounter IDs -> monsters, followed by a per-monster index. Encounter contents are listed in
[Encounter Codes](../../battle/encounter-codes/) and the per-terrain world-map tables in
[World Map Encounters](../../worldmap/world-map-encounters/); this page only adds the location and the disc.
The trigger paths themselves are described in [Encounter Trigger Runtime](../../battle/encounter-trigger-runtime/).

## How encounters are found

| Source                  | Data                                                                                                                                                         | Kind in the tables below       |
|-------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------|--------------------------------|
| Field random encounters | `<field>.mrt` (four encounter IDs) when `<field>.rat` is not zero, see [Battle related](../../field/field-file-format/battle-related/)                       | Random                         |
| Field scripted battles  | `PSHN_L id`, `PSHN_L flags`, [BATTLE](../../field/field-opcodes/069-battle/) in the `.jsm`                                                                   | Scripted (flag +1 = no escape) |
| World map               | `wmsetus.obj` section 0 (region, ground) -> section 3 group of eight IDs; in world-map state 4 (after the Lunar Cry) groups 80+ (Esthar) come from section 5 | World map                      |
| Items                   | Magical Lamp starts encounter 811 (Diablos)                                                                                                                  | Scripted                       |

Random field tables only fire while the field script leaves battles enabled (`BATTLEON` / `BATTLEOFF`), and many
scripts gate that on the main story variable (savemap word 256, see [Variables](../../miscellaneous/variables/)).

## Disc boundaries

The disc is read from the main story variable. The debug room `testbl6` switches discs with the `DISC` opcode after
writing the story value of each disc start:

| Story value | Meaning                                                                              |
|-------------|--------------------------------------------------------------------------------------|
| < 392       | Disc 1 (the parade float field `glyagu1` writes 392 after the Seifer / Edea battles) |
| 395         | Disc 2 start                                                                         |
| 901         | Disc 3 start                                                                         |
| 3860        | Disc 4 start                                                                         |

Examples of story gates on random battles:

| Fields                      | Gate                         | Effect                             |
|-----------------------------|------------------------------|------------------------------------|
| `gg*` (Galbadia Garden)     | `story < 392` -> `BATTLEOFF` | no battles during the disc-1 visit |
| `glwater*` (Deling sewers)  | `story < 385` -> `BATTLEOFF` | battles from the parade night on   |
| `bgmon_*` (Training Center) | byte 479 == 0 -> `BATTLEOFF` | not story based                    |
